# Resume — HTML Version

A simple résumé webpage built with HTML as a practice project.

## Overview

This project explores how to structure résumé content on a webpage using headings, paragraphs, lists, and links.

## Getting Started

1. Clone the repository.
2. Open `index.html` in your browser.

## Project Structure

- `index.html` — résumé webpage
- `contact.html` — supporting contact page
- `hobbies.html` — supporting hobbies page
- Image and other static assets — resources used by the pages

## Learning Focus

- Structuring information with semantic HTML
- Presenting education and experience clearly
- Linking multiple pages
- Organizing static website assets

## Before Publishing

Review all résumé details and linked pages before sharing this repository publicly. Remove any personal contact information that you do not want publicly accessible.

## Status

A basic HTML résumé project that can be extended with CSS and responsive design.
